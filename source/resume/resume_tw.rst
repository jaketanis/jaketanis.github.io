Jake Tanis
==========

Technical Writer \| Documentation Engineer
------------------------------------------

I build user-facing, software documentation for both SaaS software
companies and hardware companies. I develop scripts to prevent
implementation issues and increase productivity for documentation
workflows.

I am skilled in a variety of documentation tools and processes such as
docs-as-code, MadCap Flare, Markdown, API documentation, HTML5 help
systems, CSS, and HTML. I am also comfortable working with programming
tools such as Flask, Python, Postman, cURL, Powershell, Git, GitHub,
command-line interface commands (CLI), SVN, IIS, Azure, and Cursor.

For examples of my writing and code, see my
`portfolio <https://jaketanis.github.io/j.k.-tanis/index.html>`__ or
`GitHub <https://github.com/jaketanis>`__.
